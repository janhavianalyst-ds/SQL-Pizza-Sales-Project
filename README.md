# SQL-Pizza-Sales-Project
**Pizza Sales Analysis Using SQL**

Project Overview

This project analyzes pizza sales data using MySQL to understand order volume, revenue, product performance, category trends, and ordering patterns.

The analysis uses SQL queries to answer business-oriented questions and identify key sales insights from the dataset.

**Tools & Technologies**

MySQL
,SQL
,SQL JOINs
,Aggregate Functions
,GROUP BY & ORDER BY
,Subqueries
,Date & Time Functions

**Business Questions**

The analysis answers questions such as:

1) Retrieve the total number of orders placed.

2) Calculate the total revenue generated from pizza sales.

3) Identify the highest-priced pizza.

4) Identify the most common pizza size ordered.

5) List the top 5 most ordered pizza types along with their quantities.

6) Find the total quantity of each pizza category ordered.

7) Determine the distribution of orders by hour of the day.

8) Find the category-wise distribution of pizzas.

9) Group the orders by date and calculate the average number of pizzas ordered per day.

10) Determine the top 3 most ordered pizza types based on revenue.

**Analysis Performed**

Developed 10 SQL queries to analyze:

Overall order volume and revenue

Pizza size and product popularity

Category-wise sales performance

Hourly ordering patterns

Average daily pizza orders

Top revenue-generating pizza types
